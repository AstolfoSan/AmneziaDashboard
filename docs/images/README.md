# Documentation screenshots

The twelve RU/EN PNGs are real local browser/Windows-application captures using
synthetic DEMO fixtures only. There is no production session, server address,
credential, profile or invitation in these images. Native installer captures
use documentation-only addresses and disable SSH provisioning and downloads.

Images are normalized without resizing, cropping or altering UI pixels; text,
EXIF and other source metadata are not retained. Reviewed exact paths/hashes
are in REVIEWED.json. The privacy gate rejects unreviewed or modified images.
If changing a screenshot, visually review the actual pixels again before
updating the allowlist. Never use a real user's account for screenshot data.

Web preview: `python tools/preview_ui.py`; open the printed loopback URL.
Windows preview: `AmneziaDashboardSetup.exe --demo --lang en` (or `ru`).
These screenshots do not prove successful clean-VPS provisioning.
