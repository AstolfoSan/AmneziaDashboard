## Ваш сервер. Ваши подключения.

AmneziaDashboard — независимая веб-панель для совместимого **AmneziaWG 3.1**.
Выдавайте персональные `.vpn` для официального приложения AmneziaVPN,
распределяйте устройства по администраторам и группам, смотрите статистику
и ограничивайте доступ без ручного редактирования каждого конфига.
Это не официальный продукт Amnezia и не сервис платных VPN-подписок.

> [!IMPORTANT]
> **1.0.0 — версия исходников и пакета, а не обещание завершённой проверки установщика.**
> Для панели есть автоматические регрессионные тесты. Полный прогон нового
> прямого/каскадного установщика на чистых VPS и реальных клиентах ещё необходим.
> Не запускайте его поверх действующего VPN. Подробности — в [VALIDATION.json](VALIDATION.json).

## Возможности

- Выдача персональных `.vpn`, копирование ключа и добавление в AmneziaVPN.
- Наглядная инструкция со скриншотами и ссылки на официальные приложения.
- Иерархия «Главный администратор → Администратор → Группа → Устройство».
- Приглашения, ручная пауза доступа, срок действия и общий лимит трафика.
- Срок по умолчанию для новых клиентов группы.
- Счётчики трафика за всё время, итоги по группам и администраторам.
- Графики за последние 1/6/24 часа и 7/31 полный день; ограниченное хранение детализации.
- Разделение прав, защита запросов CSRF/Origin и понятный журнал действий.
- Пошаговый мастер установки в терминале: прямой VPN или каскад двух VPS.
- Ограниченный SSH-агент; веб-панель не получает Docker socket.

Интерфейс панели и мастер пока **только на русском**. Документация есть на
русском и английском. Переключатель языка в 1.0.0 не входит.

## Два режима установки

| Режим | Путь трафика | Где панель |
| --- | --- | --- |
| Прямой | Устройство → зарубежный VPS → Интернет | На этом же VPS |
| Каскад | Устройство → входной VPS → зарубежный VPS → Интернет | На зарубежном VPS |

Одна панель управляет одним VPN-входом. В каскаде межсерверный AWG-туннель
передаётся внутри соединения с взаимной TLS-аутентификацией. Это не выбор
нескольких выходов и не автоматический импорт уже существующих серверов.

## Начало установки

Нужны **новые VPS Ubuntu 24.04**: один для прямого режима или два для каскада.
Публичный IPv4, root SSH, `/dev/net/tun`, от 1 ГБ RAM и 3 ГБ свободного диска
на каждом. Архитектура должна поддерживаться официальным образом; начните с amd64.
На компьютере, с которого запускаете мастер, нужен Python 3.12+.

1. Скачайте **AmneziaDashboard.zip** из [Releases](https://github.com/AstolfoSan/AmneziaDashboard/releases).
2. Проверьте SHA-256 по файлу **SHA256SUMS** и распакуйте архив целиком.
3. Выполните команды из [инструкции на русском](docs/INSTALL_RU.md).
4. Запустите `python installer/cli.py` из распакованной папки.
5. Сверьте SSH-отпечатки, подтвердите точный план и сохраните приватную папку
   восстановления у себя. Не отправляйте её в GitHub.

При новой установке мастер проверяет официальные релизы Amnezia и закрепляет
выбранные образы/коммиты. Действующие серверы он автоматически не обновляет.
Команды `curl | bash` нет; вводить SSH-пароли на чужом сайте не нужно.

## Версии и обновления

Новые версии выходят тегами и релизами GitHub. У архива сохраняется имя
**AmneziaDashboard.zip**, рядом публикуется **SHA256SUMS**. Постоянная ссылка
на свежий пакет описана в [порядке выпуска версий](docs/RELEASING.md).
Новый архив не заменяет план безопасного обновления уже работающей системы:
сначала бэкап и проверка миграции. Не запускайте мастер новой установки повторно
поверх действующего VPN.
