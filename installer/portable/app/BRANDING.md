# AmneziaDashboard

This private self-hosted dashboard is a custom project, not an official Amnezia
product. The name is user-selected. The dashboard monogram in
`static/dashboard-icon.svg` is original vector artwork, not a copy of the
official Amnezia logo.

The requested palette was sampled from the official Amnezia artwork:

- Orange `#F6A453`, blue `#7EBAD2`, purple `#9B8BC1` only.
- Pure neutral grayscale for backgrounds, borders and text: no green-tinted neutrals.
- Dark state backgrounds derive exclusively from those accents mixed with neutral
  surfaces. The monogram has three solid-colour strokes and a neutral frame;
  its former teal/yellow gradient was removed on 2026-10-25.
- The only non-brand chromatic exceptions are semantic red error/destructive
  indicators and the explicitly requested green recent-handshake dot. Allowed
  access badges use the brand blue; inactive dots use neutral gray.

Reference: [official Amnezia artwork](https://github.com/amnezia-vpn/amnezia-client/blob/02838a94d5600bdc4ba9f898d8735cbe7d2f2cdc/client/images/AmneziaVPN_Full_logo.svg).
The reference artwork is CC-BY-SA 4.0 per its adjacent `.license` file. No paths,
lettering, raster artwork or other graphic content from that file were copied
into the custom dashboard icon. There are no external image or font requests.
