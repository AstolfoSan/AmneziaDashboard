    ✓

    Всё готово!

    Приложение должно быть установлено. Выберите его в первом шаге — нужный формат появится ниже.

    Android: кнопка откроет импорт в AmneziaVPN. iPhone/iPad: выберите AmneziaVPN в системном меню передачи файла. Импорт не включает VPN автоматически — подтвердите добавление и подключение в приложении.

    Не пересылайте свой файл другим людям. Для другого устройства получите отдельный профиль по приглашению.

    Кнопки повторной загрузки доступны в этом браузере 24 часа. Срок VPN-доступа задаёт администратор: по его окончании доступ приостанавливается, а клиент и конфиг сохраняются.

  3. Добавьте его в приложениеВыберите способ добавления для установленного приложения. Для AmneziaVPN доступны файл .vpn и ключ, для AmneziaWG — файл .conf.
    Для ручного добавления сначала нажмите «Скопировать ключ» на этой странице. Если появится запрос доступа к буферу обмена, разрешите вставку. Подтвердите добавление подключения, затем нажмите «Подключиться». Вид приложения может немного отличаться на разных устройствах.
    Добавление в AmneziaWG

    Нажмите «Добавить в AmneziaWG» и выберите приложение в системном меню. Если передача недоступна, скачайте .conf.

    Откройте AmneziaWG, добавьте туннель из файла .conf и подтвердите подключение. На iPhone также можно открыть файл через «Файлы» → «Поделиться» → AmneziaWG.

    Нужна версия AmneziaWG с поддержкой AWG 3.1. Это не конфиг для обычного WireGuard. Срок, пауза и лимит трафика остаются прежними.
